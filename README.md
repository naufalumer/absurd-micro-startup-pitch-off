TokenDiet: a $5-a-month service that shrinks a lazy AI agent's own 40,000-token chat history into a 200-token cheat sheet before each run, so it stops paying to re-read words it already wrote. A tiny deterministic program that writes the pitch to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
